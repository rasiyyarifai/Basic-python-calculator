# Basic-python-calculator

A lightweight and user-friendly desktop calculator application built with Python. 

 ✨ Features
* Basic Arithmetic: Perform addition, subtraction, multiplication, and division.
* Clean Interface: Designed with a custom color theme and easy-to-read button layout.
* Clear/Delete Function:** Easily clear inputs using the dedicated delete button.

 🛠️ Built With
* Python
* Tkinter (for the graphical user interface)
